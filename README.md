# DeepSeek Chat · 单文件网页客户端

> 不受 C 端对话次数限额，按 API 用量计费。

一个不需要后端、不需要构建、只有一个 HTML 文件的 DeepSeek API 聊天客户端。

它不是一个“套壳聊天页”，而是尽量保留了 DeepSeek 网页端的交互习惯，同时把**对话数据、分支结构、导入导出和长期备份**掌握在本地：

- 单文件：`deepseek-chat.html`
- 无第三方依赖、无 CDN、无后端
- 直接调用 DeepSeek 官方 API
- **不走 C 端聊天配额，对话次数不受“今日额度”限制**
- 对话保存在浏览器本地
- 支持完整分支、图片、长对话、官方网页端导出 ZIP 的勾选导入

> 近期 DeepSeek C 端产品策略有所调整，网页端会话的长期保存、迁移和本地管理变得更值得提前准备。这个文件适合作为一个可长期留存的轻量客户端，也适合放到 GitHub Pages 或自己的静态服务器上。

> 本项目不是 DeepSeek 官方产品。

## 为什么说对话不限次数

这一轮 C 端调整里，最让用户难受的通常不是界面变化，而是**对话次数/额度限制**：聊到一半提示“今日额度已用完”，或者为了省额度不敢继续追问。

这个客户端走的是 **DeepSeek API**，不经过 C 端网页/App 的聊天配额。只要 API 账户可用，就可以继续新建对话、继续追问，没有“今天只能聊 N 次”的限制——可以理解为“**对话无限额**”。本地保存的对话数量也没有人为上限，只受浏览器存储空间影响，但 token 仍然按量计费。

| | C 端网页 / App | 本项目（API 客户端） |
| --- | --- | --- |
| 对话次数 | 受 C 端额度/次数限制 | 不受 C 端聊天配额限制 |
| 计费方式 | 会员/额度体系 | 按 API 实际 token 计费 |
| 对话数据 | 保存在平台 | 保存在浏览器本地，可完整导出 |
| 历史迁移 | 取决于平台导出能力 | 支持官方 ZIP、完整 JSON、Markdown |
| 分支与旧提问 | 取决于网页端功能 | 可编辑旧提问并保留分支 |

但需要把话说清楚：

> **“不限次数”不等于“免费无限 token”。**  
> API 按实际输入/输出 token 计费，并受账户余额、API 速率限制、单次请求 48 MiB 上限和模型 1M 上下文长度约束。真正不受限的是“对话轮次/次数”，不是账单。

另外，**C 端会员/额度与 API 账户是两套体系**。网页端会员不会自动变成 API 余额，API 需要在 DeepSeek 开放平台单独开通和充值。

对经常长聊、反复修改旧问题、保留大量分支的人来说，这种方式更可控：

- 不需要为了省 C 端次数而不敢继续问
- 用多少 token 付多少费用，而不是被固定次数卡住
- 对话、分支、图片和导出数据都留在本地
- 可以随时换设备导入，不依赖网页端会话是否还能访问

如果你每天的使用量不大，API 的实际花费可能比为了额度升级会员更划算；如果用量很大，建议在 DeepSeek 开放平台关注余额和用量。

实际计费价格以官方页面为准：  
<https://api-docs.deepseek.com/quick_start/pricing>

## 快速开始

### 1. 下载文件

从仓库下载：

```text
deepseek-chat.html
```

不需要安装 Node.js，不需要执行 `npm install`，也不需要启动服务器。

### 2. 打开文件

用 Chrome、Edge 或其他现代浏览器直接打开 `deepseek-chat.html`。

也可以在文件管理器中右键选择“打开方式 → Chrome”。

### 3. 配置 API Key

1. 打开 DeepSeek 开放平台并创建 API Key：  
   <https://platform.deepseek.com/api_keys>
2. 点击页面右上角的「设置」
3. 填入 API Key
4. 确认 Base URL 为：

```text
https://api.deepseek.com
```

5. 保存

API Key 只保存在当前浏览器的 `localStorage` 中，不会写入导出的对话文件。

### 4. 开始聊天

在底部输入框输入内容，按 Enter 发送，Shift + Enter 换行。

## 使用指南

### 基本对话

1. 在输入框输入问题
2. 按 Enter 或点击发送
3. 回复会流式显示
4. 生成过程中，发送按钮会变成停止按钮

可以在「设置」中调整：

- 模型
- 深度思考开关
- 温度（Temperature）
- API Base URL

### 图片与视觉

支持格式：

```text
JPG / JPEG / PNG / GIF / WebP
```

上传方式：

- 点击输入框左侧图片按钮
- 直接粘贴截图
- 把图片拖进输入框

限制与处理：

- 每条消息最多 **6 张图片**
- 单张原图最大 **32 MB**
- 上传前会在本地压缩，最长边不超过 **2048px**
- 优先转换为 **WebP quality 0.9**，失败时回退 JPEG
- GIF 只保留第一帧
- 图片会以 base64 data URL 的形式随请求发送

视觉能力：

- 只有 `deepseek-flash` 支持图片
- 当前模型是 `deepseek-v4-pro` 时，添加图片会自动切换到 Flash
- 图片只允许出现在用户消息中

> 图片会发送给 DeepSeek API 进行处理，请不要上传包含敏感信息的图片。

### 编辑旧提问与分支

这是本项目和普通聊天页比较不一样的地方。

每条**用户消息**下方都有：

- ✏️ 编辑并重新生成
- 复制

点击编辑后：

1. 弹窗显示原提问
2. 修改文字
3. 原消息中的图片会保留
4. 点击「保存并重新生成」

默认行为：

- 从修改后的提问创建一个新分支
- 原提问、原回复和后续对话全部保留
- 消息下方出现分支切换按钮，例如 `2 / 2`
- 可以随时切回旧分支

如果关闭「编辑历史消息并重新生成」：

- 保存后会覆盖原提问之后的对话
- 会先弹出确认窗口
- 确认后旧分支被删除

> 建议保持分支开启。这样调整旧输入不会破坏原来的对话链路。

### 重新生成

每条助手回复下方有重新生成按钮。

- 开启分支时：创建新的助手分支，旧回复保留
- 关闭分支时：删除该回复之后的对话并重新生成（会确认）

### 上下文进度条

输入框底部会显示：

```text
上下文  ████░░░░  20%
```

- 数字表示**已用百分比**
- 悬停可查看估算的已用 token、总上下文和剩余 token
- 达到 70% 变橙色
- 达到 90% 变红色
- 超过 100% 会提示新建对话

统计范围：

- 当前对话的所有历史用户消息与助手回复
- 当前输入框中的草稿
- 待发送图片（每张按最多 1024 token 估算）
- 不统计思考过程，因为 `reasoning_content` 不会再次发送给 API

说明：

- 两个模型的上下文长度都是 **1M tokens**
- 进度条是本地估算，不是精确 tokenizer
- 文本按 UTF-8 字节数 ÷ 3 估算，每条消息额外加固定开销

### 超长对话

默认只渲染**最近 100 轮**对话。

- 打开很长的对话时，不会一次性创建几千条消息的 DOM
- 向上滚动到顶部，会自动加载更早的 100 轮
- 也可以点击顶部的「加载更早的对话」
- 加载时会保持当前阅读位置

重要：

- **只限制渲染，不截断数据**
- `conv.messages` 仍然保存完整对话
- 发送 API 时仍然携带完整上下文
- 导出仍然包含完整内容

### 导入导出

导入菜单有三个入口：

#### 1. 完全导入（含分支）

用于导入本应用导出的完整 JSON：

- 保留 `mapping` 中的所有分支
- 保留工具记录和文件元数据
- 保留图片

#### 2. 仅导入当前历史

用于导入本应用导出的历史备份：

- 只取当前显示那条路径
- 自动转换为线性对话
- 图片保留

#### 3. 官方网页端导出（ZIP）

见下一节。

导出菜单：

- 当前对话 Markdown
- 当前历史 JSON
- 完全含分支 JSON
- 全部对话历史备份
- 全部对话完整备份

> 完全导出适合长期归档；当前历史导出适合迁移到其他只支持线性对话的工具。

### 导入官方网页端 ZIP

适用于 DeepSeek 网页端导出的数据包，例如：

```text
deepseek_data-2026-11-18.zip
```

ZIP 内部结构一般包含：

```text
chat_session_index.json
chat_sessions/
  <会话ID>.json
  <会话ID>_files/
    <图片文件>
```

操作步骤：

1. 顶部「导入」→「官方网页端导出（ZIP）」
2. 选择 ZIP 文件
3. 等待读取会话索引
4. 在弹窗中搜索、排序、勾选
5. 点击「导入选中」

选择窗口功能：

- **搜索**：按会话标题搜索
- **最近更新**：按 `updated_at` 倒序
- **会话最长**：按消息条数倒序
- **勾选导入**：只读取选中的会话
- 显示每条会话的日期、消息条数、是否置顶

导入行为：

- 保留官方会话的树结构和分支
- 使用 `current_message_id` 恢复当前分支
- 图片会从 ZIP 的 `_files` 目录读取并转为 data URL
- 非图片附件（PDF、CSV 等）保留文件元数据，但当前不提供预览/下载
- 只读取索引和选中会话，不会把 ZIP 中所有会话全部解析

搜索说明：

- 当前是**标题搜索**，不是全文搜索
- 全文搜索需要加载所有会话，代价较大，暂未实现

浏览器要求：

- 需要支持 `DecompressionStream`
- 推荐使用较新的 Chrome / Edge / Android Chrome
- 暂不支持 ZIP64、分卷 ZIP、加密 ZIP

### 主题、全屏与快捷键

快捷键：

| 快捷键 | 功能 |
| --- | --- |
| Enter | 发送 |
| Shift + Enter | 换行 |
| Esc | 关闭弹窗 / 菜单 / 图片预览 |

主题：

- 顶部主题按钮切换浅色 / 深色
- 选择会保存在本地

全屏：

- 顶部全屏按钮
- 主要用于 Android Chrome，隐藏地址栏和系统栏

## 数据与隐私

### 保存在哪里

| 数据 | 保存位置 |
| --- | --- |
| API Key | `localStorage` |
| 设置 | `localStorage` |
| 当前对话 ID | `localStorage` |
| 对话正文 / 分支 / 图片 | IndexedDB（不可用时回退 localStorage） |

### 不会上传到什么服务器

- 没有自建后端
- 没有统计脚本
- 没有第三方 CDN
- 对话只发送给配置的 DeepSeek API Base URL

### 导出文件

- 导出的 JSON 不会包含 API Key
- 图片会以 base64 / data URL 写入导出文件
- 带图片的导出文件会明显变大
- 完整导出包含所有分支，历史导出只包含当前路径

### 清除浏览器数据的风险

以下操作会删除本地对话：

- 清除浏览器站点数据
- 卸载浏览器
- 更换浏览器
- 更换访问地址（例如从 `file://` 改成 GitHub Pages）
- 无痕模式关闭窗口

> 建议定期使用「导出 → 全部对话完整备份」。

### API Key 安全

- API Key 保存在浏览器本地，不会写入导出文件
- 不要在不可信的修改版页面中输入 API Key
- 如果页面被注入了恶意脚本，API Key 可能被读取
- 建议使用自己审查过的版本，或部署到自己控制的静态站点

### 上传 GitHub 前

不要把私人数据提交到公开仓库：

- API Key 文件（例如 `api.txt`）
- 官方导出的 ZIP
- 解压后的 `chat_sessions/` 目录
- 导出的对话 JSON / Markdown
- 包含个人信息的截图
- `.idea/` 等编辑器本地配置

仓库根目录附带了一份 `.gitignore`，默认排除：

```gitignore
# 私人数据
api.txt
deepseek_data-*/
deepseek_data-*.zip
chat_sessions/
deepseek-full-*.json
deepseek-history-*.json
conversations.json

# 本地文件
.idea/
preview-*.png
```

正常情况下只提交：

```text
deepseek-chat.html
README.md
.gitignore
```

## 部署到 GitHub Pages

这个项目适合直接托管：

1. 新建一个 GitHub 仓库
2. 上传 `deepseek-chat.html`
3. 将文件重命名为 `index.html`，或保留原名并创建跳转
4. 仓库 Settings → Pages
5. Source 选择部署分支和根目录
6. 访问生成的 Pages 地址

注意：

- GitHub Pages 使用 HTTPS 静态页面，不涉及后端
- API Key 保存在该 Pages 域名的浏览器存储中
- 从 `file://` 切换到 Pages 域名后，原来的本地对话不会自动迁移
- 切换前请先导出，再在新地址导入

如果访问 API 时遇到 CORS 错误：

- 检查 Base URL 是否允许浏览器跨域访问
- 如有必要，使用自己的、支持 CORS 的 API 代理地址
- 本项目不包含代理服务器

## 浏览器兼容性

推荐：

- 桌面 Chrome / Edge 最新版
- Android Chrome 最新版

需要的能力：

- Fetch / ReadableStream
- IndexedDB
- Canvas `toDataURL`
- `DecompressionStream`（仅官方 ZIP 导入需要）
- CSS `:has()`（用于列表选中高亮，不支持也不影响导入）

不推荐：

- 旧版 Android WebView
- 不支持 `DecompressionStream` 的浏览器
- 禁用本地存储的隐私模式

## 常见问题

### 1. 提示「请先配置 API Key」

打开右上角设置，填入 API Key 并保存。

### 2. 提示 API Key 无效 / 401

- 检查 Key 是否复制完整
- 确认 Key 未过期
- 确认 Base URL 是 `https://api.deepseek.com`

### 3. 提示网络请求失败 / CORS

- 检查网络
- 检查 Base URL
- 如果使用代理，确认代理允许浏览器跨域请求
- 直接用 `file://` 打开时，部分代理配置可能不允许跨域

### 4. 图片上传后没有反应

- 等待图片处理完成，发送按钮会短暂显示加载状态
- 检查图片格式是否在支持范围内
- 单张图片不要超过 32 MB
- 如果是 Pro 模型，系统会自动切换到 Flash

### 5. 深度思考过程看不到

深度思考需要先在输入框下方开启「深度思考」。

开启后，助手回复上方会出现可折叠的思考过程面板；点击标题展开。

### 6. 长对话打开很慢

当前版本默认只渲染最近 100 轮，正常情况下会明显快于全量渲染。

如果仍然很慢，可能原因：

- 对话中包含大量图片
- 浏览器 IndexedDB 读取较慢
- 设备内存不足

### 7. 上下文进度条显示 100%

可能原因：

- 当前对话已经接近 1M token
- 尚未发送的草稿或图片也计入了估算

建议新建对话，或先导出备份。

### 8. 官方 ZIP 导入失败

检查：

- 文件是否是网页端导出的 ZIP
- ZIP 根目录是否有 `chat_session_index.json`
- 浏览器是否支持 `DecompressionStream`
- ZIP 是否被加密、分卷或 ZIP64

### 9. 导入后消息比列表里的「条数」少

官方会话可能包含分支。

- 列表中的条数是整棵树的消息数
- 导入后默认显示导出时的当前分支
- 其他分支可以通过消息下方的分支按钮切换

### 10. 忘记导出，清除浏览器数据了

本地数据无法从服务器恢复。这个项目没有云端备份。

### 11. “对话无限额”是不是可以免费无限用？

不是。

- **不限**的是 C 端网页/App 那种对话次数或当日额度
- **仍然要付** API 的 token 费用
- 仍然受账户余额、API 速率限制、请求体大小和 1M 上下文限制

简单说：不再被“今天只能聊几次”卡住，但用多少 token 仍然会计费。

## 已知限制

- 不是 DeepSeek 官方客户端
- 不提供云端同步
- 上下文百分比是本地估算，不是精确计费 token

- API 可用性、模型名称和价格由 DeepSeek 官方决定
- 浏览器本地存储有容量上限，图片多时建议定期导出并清理
